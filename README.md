# 💰 Finance App

A modern and intuitive **Finance App built with Flutter**, designed to provide a clean user experience for exploring personal finance features through a responsive and visually appealing interface.

The project focuses on modern UI design, reusable Flutter components, and data visualization to create a smooth mobile app experience.

## ✨ Features

- 📊 **Financial Charts** — Visualize financial data using interactive charts.
- 📱 **Responsive UI** — Adapt layouts to different screen sizes.
- 🎨 **Modern Design** — Clean interface with custom typography.
- 🔢 **PIN Code Input** — Specialized input fields for PIN-based interfaces.
- 🎠 **Carousel Components** — Display content in swipeable carousels.
- 🧭 **Page Indicators** — Clear visual indicators for carousel navigation.

> Note: These features describe the capabilities of the packages used in the project. Adjust this list to match the functionality currently implemented in the app.

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

- Flutter SDK installed
- Dart SDK compatible with your Flutter installation
- Android Studio, VS Code, or another supported IDE
- An emulator or physical device

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/mailaymanis/finance-app.git
   ```

2. Navigate to the project directory:

   ```bash
   cd finance-app
   ```

3. Install dependencies:

   ```bash
   flutter pub get
   ```

4. Run the application:

   ```bash
   flutter run
   ```
